# TKOH Booking System — 技術架構說明

## 一、系統概述

本系統為醫院內部資源線上預訂平台，涵蓋場地預訂、電動車充電位預訂、管理後台及場地資訊大屏展示等功能。整體採前後端分離架構，並以容器化方式部署，便於維護與升級。

系統主要分為三個部分：

| 部分 | 說明 |
|------|------|
| Web 前端 | 使用者預訂介面、管理後台、大屏展示頁面 |
| 後端 API 服務 | 業務邏輯、權限認證、資料處理 |
| 大屏播放器 | Windows／Android 終端全螢幕展示程式 |

---

## 二、開發語言

| 層級 | 語言 |
|------|------|
| 前端 | JavaScript |
| 後端 | TypeScript |
| 資料庫 | SQL（PostgreSQL） |
| 大屏播放器（Windows） | JavaScript（Electron） |
| 大屏播放器（Android） | Kotlin／Android 原生 |

---

## 三、技術框架與元件

### 3.1 前端（Web）

| 項目 | 技術 | 說明 |
|------|------|------|
| 核心框架 | Vue 3 | 現代化前端應用框架 |
| 建置工具 | Vite | 前端編譯與打包 |
| 路由 | Vue Router | 頁面導航 |
| 狀態管理 | Pinia | 前端資料狀態管理 |
| UI 元件庫 | Element Plus | 管理介面與表單元件 |
| 樣式 | Tailwind CSS | 介面樣式 |
| HTTP 通訊 | Axios | 與後端 API 通訊 |
| 其他 | 二維碼產生、Excel 匯出、富文字編輯器 | 業務輔助功能 |

### 3.2 後端（API）

| 項目 | 技術 | 說明 |
|------|------|------|
| 核心框架 | NestJS | 企業級 Node.js 後端框架 |
| 執行環境 | Node.js | 伺服器端 JavaScript／TypeScript 運行環境 |
| ORM／資料存取 | Prisma | 資料庫模型與遷移管理 |
| 身份認證 | JWT（Passport） | 登入驗證與權限控制 |
| API 文件 | Swagger | 介面說明與測試 |
| 排程任務 | NestJS Schedule | 定時任務（如配額重設等） |
| 郵件 | Nodemailer | 系統通知郵件 |

### 3.3 資料與快取

| 項目 | 技術 | 說明 |
|------|------|------|
| 關聯式資料庫 | PostgreSQL 15 | 儲存用戶、預訂、場地等業務資料 |
| 快取／限流 | Redis 7 | 提升查詢效能、支援高併發預訂 |

### 3.4 部署與基礎設施

| 項目 | 技術 | 說明 |
|------|------|------|
| 容器化 | Docker／Docker Compose | 應用與依賴環境打包部署 |
| 反向代理／入口 | Nginx | HTTPS、靜態資源、藍綠流量切換 |

### 3.5 大屏播放器

| 平台 | 技術 | 說明 |
|------|------|------|
| Windows | Electron + electron-builder | 打包為 `.exe` 安裝程式，全螢幕開啟大屏網頁 |
| Android | Android WebView 應用 | 全螢幕開啟大屏網頁，適合作為展示終端 |
