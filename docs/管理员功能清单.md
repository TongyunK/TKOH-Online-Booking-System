# TKOH 在线预订系统 — 管理员功能清单

> 供编写**管理员／运营产品说明**使用。覆盖 Admin 后台、代订、审批、资源与大屏配置等。  
> 系统名称常见为 **TKOH GA Venue and EV Charging Booking System**。  
> 普通用户能力见：[用户功能清单.md](./用户功能清单.md)

---

## 1. 适用对象与入口

| 项目 | 说明 |
|------|------|
| 登录入口 | 选择 **Admin Management** |
| 后台入口 | 登录后进入 **Admin**（`/admin`）；可有待办角标 |
| 角色 | 主要为 **Admin**（全功能）；**SuperAdmin** 为系统隐藏角色，对外文档可不展开 |

### Admin 相对普通用户的额外能力（摘要）

- 进入完整 Admin Panel  
- EV／Venue **代订**（指定 Reserved By）  
- 周末／公众假期仍可预订  
- EV **周限额豁免**；配额通常不限制  
- 查看／管理 **All Bookings**；场地预订 **Approve／Reject**  
- 顶栏：**Calendar**、**Manage Booking** 下拉进入 EV／Venue  

---

## 2. 管理端顶栏与待办

| 入口 | 说明 |
|------|------|
| **Admin** | 进入后台首页／菜单；显示待审批等角标 |
| **Calendar** | 下拉：EV Calendar／Venue Calendar |
| **Manage Booking** | 下拉：EV／Venue 预订管理（含全部预订视角） |
| **My Account** | 同用户侧账号页 |
| **Points to Note**／**Log out** | 须知与登出 |

待办来源通常包括：用户注册待审、会议／场地预订待审等（以角标与列表为准）。

---

## 3. 会议审批（Meeting Approval）

| 能力 | 说明 |
|------|------|
| 列表分类 | Pending／Expired／Approved（及 Rejected 相关列表能力） |
| 操作 | 搜索、日期快捷筛选、**Approve**、**Reject** |
| 拒绝 | 可选用 **Reject Template** 或填写原因 |
| 导出 | Export Excel |
| 角标 | 顶栏／侧栏待办数量 |

业务关系：用户提交场地预订后多为 **pending**，需在此（或 All Bookings 快捷操作）批准后确认。

---

## 4. EV 管理（EV Management）

| 子模块 | 能力 |
|--------|------|
| **EV Space** | 充电车位增删改、启用／停用等 |
| **Booking Period** | 预订时段维护（如 AM／PM／Night 及起止时间） |
| **Booking Date Range** | 配置并 **Publish** 用户可订日期范围 |

相关系统参数（在 System Settings）：

- **EV Date update time**：可订日期向前滚动的时间点（如每日约 13:00 HKT）  
- **EV Weekly limit**：普通用户每周活跃预订上限（如 1–7）  

管理员本人预订时：周限额豁免；假期／周末可订。

### 管理端 EV 预订管理

- 查看 **All Bookings**、筛选、搜索、编辑／取消、导出  
- 日历上可为用户 **代订**（Reserved By）  

---

## 5. Venue 管理（Venue Management）

### 5.1 Venue List

按 **Conference & Discussion**／**Other Venues** 维护场地，字段能力包括：

- 中英文名称、类型、颜色、位置  
- 容量、状态  
- **Daily Open Hours**（每日可订时段）  
- **Display Type**：Single／Merge（影响大屏）  
- 图片  
- **Blocked Periods**（封锁不可订时段）  
- 是否允许用户自定义上传活动标题等  

### 5.2 Booking Date Range

- 发布 Venue 用户可订日期窗口  

### 5.3 管理端 Venue 预订与审批

- **All Bookings**：筛选、编辑／取消、茶水信息、导出  
- 对 upcoming 可直接 **Approve／Reject**  
- 日历／表单 **代订**  
- 系统参数：**Venue Min gap**（同场最小间隔，默认约 15 分钟）、标题最大长度

## 6. 用户管理（User Management）

| 能力 | 说明 |
|------|------|
| 用户列表 | 查询、维护用户资料与状态 |
| 注册审批 | Pending／Approved／Rejected |

## 7. 权限与组织（Access Right）

| 子模块 | 说明 |
|--------|------|
| **Role** | 角色维护；可配置角色默认年配额（EV／Venue） |
| **Department／Unit** | 部门／单位维护（注册与资料下拉用） |

角色与系统访问对应关系（配置参考）：

| 角色 | EV | Venue | Admin 后台 |
|------|----|-------|------------|
| Admin | ✓ | ✓ | ✓ |
| User | ✓ | ✓ | ✗ |
| User_EV | ✓ | ✗ | ✗ |
| User_Venue | ✗ | ✓ | ✗ |

## 8. 提示与模板（Prompts and Templates）

| 类型 | 用途 |
|------|------|
| Points to Note | 登录页与浮动帮助（EV／Venue 可分开） |
| Alert Message | EV／Venue 日历页提示条 |
| 表单服务提示 | 如 Venue Setup／Equipment／Tools／Tea 等 |
| **Reject Template** | 拒绝用户注册、拒绝会议／场地申请等模板 |

> 对外说明书中的「须知」内容，**以本模块现网配置为准**，勿只抄种子默认文案。

---

## 9. 车牌管理（License Plates）

- 管理员维护用户车牌（绑定、增删改等）  
- 与用户 **My Account → Vehicle Information** 互补：用户侧重查看／设默认，完整维护在后台  

---

## 10. 大屏管理（Display Management）

| 能力 | 说明 |
|------|------|
| Display Rules | Single／Merge、Display Name 等规则 |
| Preview Links | 预览：场地单屏、合并屏、茶水屏、EV 屏 |
| Merge 定制 | 标题、底部 ticker、二维码等 |

### 公共展示屏一览（免登录，供现场投放）

| 屏幕 | 内容要点 | 管理关注点 |
|------|----------|------------|
| Venue 单屏 | 今日活动、场地中英名／位置、时钟 | 与场地 Display Type／规则相关 |
| Venue 合并屏 | 多会议室 AM／PM 日程、标题、QR、滚动条 | Merge 定制项 |
| 茶水服务屏 | 按日／场地／上下午列茶水需求；可勾选完成 | 运营人员现场操作 |
| EV 展示屏 | 今日预约车牌；时段 × 车位；滚动条 | 与 EV 当日预订同步 |

产品说明可将「展示屏」写成运维／前台使用的独立章节，并链到本清单预览链接说明。

## 11. 系统设置（System Settings）

| 设置项 | 说明 |
|--------|------|
| **User Inactivity** | 长期未登录自动 Inactive（Admin 通常除外） |
| **Auto Logout** | 空闲自动登出分钟数（对用户与管理员普遍生效） |
| **HK Public Holidays** | 公众假期数据源；可触发同步 |
| **EV Date update time** | EV 可订日期滚动时刻 |
| **EV Weekly limit** | EV 每周上限 |
| **Venue Min gap** | 同场地预订最小间隔（分钟） |
| **Meeting／Event Title max length** | 标题长度上限（中文常按 2 单位计） |
| **Data Backup** | 备份接收邮箱、定时发送、**立即发送备份** |

### 偏运维、文档宜谨慎表述的项

以下后端可能支持，但 Admin 表单未必完整暴露——写入产品说明前请与实施／开发确认：

- 数据保留（Data Retention）月数与定期清理策略  
- 备份 SMTP 账号等敏感配置  
- 大屏轮播／ticker 时长等细项  
- Data Backup 的时间跨度／间隔等扩展字段

## 12. 数据与合规类能力（管理／运维）

| 能力 | 说明 |
|------|------|
| 年配额清零 | 每年 1 月 1 日（HKT）已用配额清零；亦可手动重置 |
| 数据备份 | 定时或即时生成报表／Excel 并邮件发送 |
| 数据保留 | 超龄预订、符合条件的 Inactive 用户定期清理（策略向） |
| 健康检查 | 运维用接口，不写入业务用户手册 |

---

## 13. 管理员需向用户解释的规则（简表）

便于客服／管理员答疑，详细用户表述见用户清单。

| 域 | 规则要点 |
|----|----------|
| 共用 | 可订窗口由 Admin Publish；非 Admin 不可订周末／公众假期；空闲自动登出 |
| EV | 周限额、年配额、每格车位数、系统分位 |
| Venue | 每日开放时段、封锁时段、最小间隔、年配额、标题长度、审批流、茶水近日期限制 |

---

## 14. 撰写管理员手册时的建议章节

1. 登录 Admin 与待办角标说明  
2. 会议／场地审批流程与拒绝模板  
3. EV 资源、时段与日期窗口发布  
4. Venue 场地档案、开放时间、封锁与日期窗口  
5. 用户与注册审批、角色与部门、配额重置  
6. 文案与模板维护  
7. 车牌管理  
8. 大屏规则、预览与现场展示屏操作（含茶水勾选完成）  
9. 系统设置与数据备份  
10. 代订、假期可订、All Bookings 等高权限操作说明  

界面中英并存时，以实际 UI 为准；配置类说明建议配截图与「发布后用户侧何时生效」的一句话。
