# TKOH 在线预订系统 — 用户功能清单

> 供编写**普通用户产品说明／操作手册**使用。仅覆盖终端用户可见能力。  
> 系统名称常见为 **TKOH GA Venue and EV Charging Booking System**。  
> 管理员相关能力见：[管理员功能清单.md](./管理员功能清单.md)

---

## 1. 适用对象与系统入口

本清单面向使用 **EV Booking（充电车位）** 与／或 **Venue Booking（场地）** 的员工用户。

登录时选择入口：

| 入口 | 谁选 |
|------|------|
| **EV Booking** | 需要预订充电车位的用户 |
| **Venue Booking** | 需要预订会议室／场地的用户 |

> 普通用户一般不选 **Admin Management**。

### 角色与能做什么（用户视角）

| 角色 | EV | Venue | 说明 |
|------|----|-------|------|
| **User** | ✓ | ✓ | 顶栏可在两个系统间切换 |
| **User_EV** | ✓ | ✗ | 仅充电预订 |
| **User_Venue** | ✗ | ✓ | 仅场地预订；账号页无车牌区块 |

配额由管理员配置。用尽后系统会拒绝新预订（界面提示配额不足）。

## 2. 登录、注册与安全

| 功能 | 说明 |
|------|------|
| 登录 | CORP ID + 密码，并选择 EV／Venue 入口 |
| 注册申请 | 填写 CORP User ID、Employee No.、Department／Unit、Rank 等，提交后等待管理员审批 |
| 登录页须知 | 展示当前所选系统的 **Points to Note** |
| 登出 | 顶栏 **Log out** |
| 空闲自动登出 | 一段时间无操作后自动退出（时长由管理员配置，常见约 30 分钟） |
| 页内帮助 | 浮动 **Points to Note**，随时查看须知 |

---

## 3. 登录后顶栏（用户）

| 入口 | 说明 |
|------|------|
| **Book Now** | 进入当前系统的预订日历 |
| **My Bookings** | 查看与管理本人预订 |
| **My Account** | 个人资料、改密、车牌（视角色） |
| **Switch EV／Venue Booking** | 双系统用户在 EV 与 Venue 间切换 |
| **Points to Note** | 打开须知 |
| **Log out** | 退出 |

## 4. EV 充电车位预订

### 4.1 预订日历（Book Now）

- 多周网格：按 **日期 × 时段（上午 AM／下午 PM／夜间 Night）** 显示是否还有余位（如 Available／Full）
- 周末、公众假期有特殊样式
- 可显示 **Alert Message** 提示条
- 点击空档／格子打开预订弹窗

### 4.2 创建与修改预订

| 项目 | 说明 |
|------|------|
| 车牌 | 从本人已登记车辆中选择 |
| 时段 | AM／PM／Night（具体钟点以系统配置为准；常见约 08:30–13:00、13:45–18:15、19:00–23:30） |
| 日期 | 须在管理员已开放的可订日期范围内 |
| 车位 | 新建时由系统自动分配；编辑时或可选车位 |
| 编辑／取消 | 在规则允许时于日历或「我的预订」中操作 |

### 4.3 我的预订（My Bookings）

- 查看本人 EV 预订列表
- 按状态筛选（含已取消）、搜索
- 编辑、取消
- 可导出 Excel（若界面提供）

### 4.4 用户须知的业务规则（EV）

| 规则 | 用户侧表现 |
|------|------------|
| 可订日期范围 | 超出管理员发布的日期窗口则无法预订 |
| 周末／公众假期 | 一般员工不可订 |
| 每周限额 | 默认每周通常仅可有 **1** 条有效预订（以现网设置为准） |
| 年配额 | 年度次数用尽后无法再订 |
| 车位已满 | 该日该时段显示 Full／提交时提示已满 |
| 须知与提示 | 以登录页／浮动 Points to Note、日历 Alert 为准 |

## 5. Venue 场地预订

### 5.1 入口与场地类型

进入 Venue 后常见两类：

1. **Conference Rooms and Discussion Room**（会议室／讨论室）  
2. **Other Venues**（其他场地）

各自进入对应日历。场地举例：Conference Room 1–3、Discussion Room、Function Room、Lecture Theatre、Auditorium（以现网为准）。

### 5.2 预订日历

- 视图：**日／周／月**
- 可按房间筛选
- **Add Booking** 新增预订
- 可显示 **Alert Message**

### 5.3 填写预订表单

| 项目 | 说明 |
|------|------|
| Room | 选择场地 |
| Date、Start／End Time | 日期与起止时间 |
| CHECK AVAILABILITY | 检查该时段是否可订 |
| Meeting／Event Title | 会议／活动标题（有长度限制） |
| My Note | 备注 |
| No. of participants | 参加人数 |
| Tea Service Required | 是否需要茶水；可选茶水方案与特殊要求 |
| 服务相关提示 | 如场地布置、设备、物料等说明（只读提示） |
| Department／Unit、Contact | 部门与联系方式等 |

提交后，场地预订通常需 **管理员审批**，状态可能为待审批，批准后方为确认（以界面状态名为准）。

### 5.4 我的预订（My Bookings）

- 查看本人场地预订
- 状态筛选、列显示设置
- 编辑／取消（规则允许时）
- 查看茶水相关信息
- 可导出（若界面提供）

### 5.5 用户须知的业务规则（Venue）

| 规则 | 用户侧表现 |
|------|------------|
| 可订日期范围 | 仅管理员开放窗口内可订 |
| 周末／公众假期 | 一般员工不可订 |
| 每日开放时段 | 各场地开放时间不同，超出则无法预订（如某讨论室仅下午可订） |
| 时段冲突／已满 | 检查可用性失败或提交失败 |
| 同场间隔 | 与相邻预订之间可能需留出缓冲时间 |
| 年配额 | Venue 年度次数用尽后无法再订 |
| 茶水修改 | 临近日期时，茶水选项修改可能受限 |
| 审批 | 待审批期间以界面状态与通知／列表为准 |

## 6. 我的账号（My Account）

| 区块 | 说明 |
|------|------|
| **User Profile** | 查看 CORP User ID、员工编号、姓名、邮箱、电话、部门、职级等 |
| **Change Password** | 修改本系统密码（勿使用 HA 登录密码） |
| **Vehicle Information** | 查看车牌、设为默认车；**User_Venue 无此区块** |

> 车牌的新增／删除等完整维护，通常由管理员在后台处理；用户端以查看与设默认为主（以实际界面为准）。

## 7. 常见拒绝原因（写进 FAQ 可用）

| 情况 | 可能原因 |
|------|----------|
| 无法选择某天 | 不在开放窗口内；或为周末／公众假期 |
| EV 预订失败 | 周限额已满、年配额不足、该时段车位已满、无可用车牌 |
| Venue 预订失败 | 时段冲突、超出房间开放时间、场地封锁、年配额不足、标题不合规等 |
| 场地一直「待审批」 | 等待管理员 Meeting Approval |
| 突然被登出 | 触发空闲自动登出，需重新登录 |
