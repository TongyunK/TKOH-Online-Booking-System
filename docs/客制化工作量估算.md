# 客制化工作量估算

一名熟悉本系統的開發人員，開發與自測約 **12～16 個工作日**。加上客戶域控、憑證與防火牆的等待，日曆時間約 **3～4 週**。

## 包含範圍

院內 Active Directory 的 LDAPS 登入、管理員綁定、門口屏占用與 Quick Book、內網鏡像交付。

| 工作 | 內容 | 人天 |
| --- | --- | --- |
| AD 登入 | 新增 `externalId`、`authSource`，密碼可空；LDAPS 綁定；改名後用 `objectGUID` 找回用戶 | 4～5 |
| 管理端綁定 | 綁定 AD 帳號、清空本地密碼、AD 用戶關閉本系統改密 | 2 |
| 門口屏 | 單會議室頁顯示當前占用；空閒時 Quick Book；按會議室開關決定是否要用戶名與密碼；一次一單，不保持登入 | 4～5 |
| 內網交付 | 只交鏡像、關閉資料庫端口映射、Docker 開機自啟、編寫現場啟動說明 | 1～1.5 |
| 聯調緩衝 | 用測試用 AD 核對：在 AD 改密碼後仍能登入、改用戶名後仍是同一人、錯誤密碼拒絕、無本地用戶拒絕、時段衝突拒絕。AD 用戶在本系統內不能改密 | 1～2 |

## 尚未定案、會加時間的項目

- 預約伺服器不能直接訪問域控，須經獨立位址轉發：再加 **1.5～2 人天**。
- 伺服器不能上公網，公眾假期來源要更換：再加 **0.5～1 人天**。

Quick Book 沿用現有規則：提交後該時段即為占用，審批只審核標題。待審批與已通過都會擋住同一時段。預訂時長（訂到下一場，或固定時長）定案後不再明顯增加工作量。

與客戶 IT 開通 LDAPS、核對憑證與防火牆，通常另需 **2～3 個工作日**，視對方排期而定。
